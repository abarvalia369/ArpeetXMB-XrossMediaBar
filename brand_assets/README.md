# brand_assets/

Drop your real brand materials here **before** building the site — Claude checks this folder
first and will use what it finds instead of placeholders.

Good things to put here:
- `logo.svg` / `logo.png` — your logo (SVG preferred)
- `palette.md` or `colors.txt` — exact hex values for your brand colors
- `fonts.md` — heading + body font names (and links if custom/self-hosted)
- Any photos of you, or imagery you want featured

If this folder is empty, Claude designs from scratch with placeholders.
